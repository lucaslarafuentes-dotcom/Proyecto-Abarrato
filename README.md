# Proyecto Abarrato

**Nuestra Promesa:**
Para las familias y pequeños comerciantes que sufren la pérdida de poder adquisitivo y el gasto innecesario de tiempo buscando los mejores precios, Abarrato es una plataforma móvil que permite consultar y comparar el valor exacto de los abarrotes en supermercados contiguos, garantizando que cada viaje de compras sea la opción más económica posible.
